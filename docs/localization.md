# Локализация интерфейса

Каталоги находятся в `src/SellerFinance.Web/src/i18n.tsx`. Русский каталог определяет тип `TranslationKey`, а остальные языки обязаны реализовать `Record<TranslationKey, string>`. Поэтому пропущенный ключ останавливает TypeScript/CI build.

Компоненты получают строки через `useI18n().t(key)`. Выбранный язык сохраняется в `localStorage` под ключом `seller-finance-locale`, а `<html lang>` обновляется автоматически.

Переведены auth, восстановление доступа, header, основная навигация, dashboard, заказы с финансовым drill-down, каталог и карточка товара, история себестоимости, импорт себестоимости, расходы, версионные комиссии и финансовый импорт. Русский и казахский каталоги для этих экранов типизированы одним набором ключей. Остальные экраны переносятся последовательно; новые строки нельзя добавлять напрямую в уже локализованные компоненты.
